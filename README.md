# Native Transmog

MHGU Recomp 的原生菜单幻化插件。可以从装备箱选择已拥有的防具作为外观，保留当前装备的属性。插件的外观可覆盖游戏原生装备合成的显示效果。

## 安装

在 MHGU Recomp 目录下创建 `mods/Native-Transmog/romfs/nativeNX/plugins/`，放入 `Native-Transmog.nro`，然后重启游戏。升级时用新文件替换此前的 `layered.nro`。在 Recomp 的 Mods 页面确认已启用。

已验证 MHGU 1.4.0、MHGU Recomp 0.18.1 和该版本的 Forge 插件加载器。

## 用法

- **猎人外观**：进入道具箱第 2 页，选择「外观装备」。在装备箱选中防具并确认，即可应用该部位的外观。「恢复原生外观」会重新显示当前装备在游戏里的外观。
- **随从外观**：进入随从看板第 2 页，选择「外观装备」，依次选择随从、部位和装备。
- **幻化个人组合**：进入道具箱第 2 页，选择「幻化个人组合」。可装备、登记、移动和解除，共 40 组。组合列表右下角的「更改名称」可打开游戏的命名键盘。
- **防具上色**：在「更改造型 → 更改防具上色」中修改当前装备部位的染色。颜色显示在幻化模型的可染区域，组合只保存外观。

## 从源码构建

安装 Python 3 和 Zig。将 Zig 加入 PATH 后，在源码目录运行 `python build.py`，生成 `Native-Transmog.nro`。也可以通过 `--zig` 指定 Zig 可执行文件。
